# NoImageDNA

An API written by [Zephyros1938](https://github.com/Zephyros1938) & [PiffleV](https://github.com/PiffleV) for avoiding algorithmic and ai image detection using symmetric encryption.

Note: Most, if not all of the encryption algorithms are probably not cryptographically secure. Don't use this for actual cryptography (if there is a cipher thats probably cryptographically secure we'll add it here)
